Hypertension Risk Screening
Fairness & Missing Data in Clinical ML

Problem

Non-communicable diseases (NCDs) drive mortality in Sub-Saharan Africa. Community screening data is beset by structural missingness (49% missing data) and demographic bias. Standard pipelines fail silently.

Methodology

  • Multivariate Imputation by Chained Equations (MICE) with Bayesian Ridge & Extra-Trees
  • Algorithmic fairness audit (DPD, DIR, EOD across sex & age)
  • Second-order SHAP interaction tensors for structural interpretability
  • Class-balanced Random Forest with calibration

Key Findings

0.649 AUROC with rigorous cross-demographic validation
Disparate Impact Ratio = 0.397 (males under-flagged)
Age×BMI interaction weaker than literature suggests
Salt-use × lifestyle interaction strongest predictor

Future Work

Dual-stream multimodal architecture integrating retinal fundus imaging with tabular EHR data via cross-attention fusion for enhanced early detection.

Dental XRAY Analysis
Medical Imaging & MLOps Pipeline

Problem

Orthopantomographic (OPG) X-ray analysis requires expert radiologists, creating bottlenecks in resource-limited dental care systems. Automated analysis could improve throughput.

Methodology

  • Transfer learning from pre-trained medical imaging models
  • End-to-end MLOps pipeline (data versioning, model registry, monitoring)

Key Findings

Achieved clinically relevant accuracy on OPG pathology detection
Robust pipeline handles production data drift
Model retraining automation reduces manual overhead

Future Work

Credit Card Fraud Detection
Imbalanced Classification & Anomaly Detection

Problem

Detecting fraud in highly imbalanced transaction data (typical fraud rate <0.1%) while minimizing false positives that frustrate legitimate users.

Methodology

  • Handling class imbalance: SMOTE, cost-sensitive learning
  • Isolation Forest for anomaly detection
  • Threshold optimization based on business cost metrics
  • Real-time scoring architecture

Key Findings

98%+ detection rate with <1% false positive rate
Ensemble outperforms single models on rare patterns

Future Work

Concept drift monitoring; adaptive retraining on emerging fraud patterns; behavioral model enrichment.
